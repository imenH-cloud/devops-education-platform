🐳 Docker & Containerisation

Multi-Stage Builds


# Stage 1: Builder
FROM node:20-alpine AS builder
COPY package*.json ./
RUN npm ci --prefer-offline
COPY . .
RUN npm run build

# Stage 2: Production
FROM node:20-alpine
COPY --from=builder /app/dist ./dist
RUN npm ci --omit=dev
USER nodejs:1001
CMD ["node", "dist/main.js"]

Résultat: 340MB (vs 1.2GB sans multi-stage)

- Explique les deux stages - Pas d'outils build en production - Sécurité + optimisation taille

☸️ Kubernetes & Orchestration

Deployments avec HA


apiVersion: apps/v1
kind: Deployment
metadata:
  name: gateway-deployment
spec:
  replicas: 2
  strategy:
    type: RollingUpdate
    rollingUpdate:
      maxUnavailable: 0
  resources:
    requests:
      cpu: 250m
      memory: 256Mi
    limits:
      cpu: 500m
      memory: 512Mi

2 replicas = Haute Disponibilité

- RollingUpdate: zéro downtime - Resource management - Autoscaling jusqu'à 5 replicas
