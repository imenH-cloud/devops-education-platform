🎯 REQUÊTES PROMQL UTILISÉES
═════════════════════════════════════════════════════════════════

CPU par Service:
  sum(rate(container_cpu_usage_seconds_total
    {namespace="education", pod=~".*service.*"}[5m])) by (pod)

Memory par Service:
  sum(container_memory_usage_bytes
    {namespace="education", pod=~".*service.*"}) by (pod)

Network RX par Service:
  sum(rate(container_network_receive_bytes_total
    {namespace="education", pod=~".*service.*"}[5m])) by (pod)

Network TX par Service:
  sum(rate(container_network_transmit_bytes_total
    {namespace="education", pod=~".*service.*"}[5m])) by (pod)

Infrastructure Memory:
  sum(container_memory_usage_bytes
    {namespace="education", pod=~"postgres|redis|rabbitmq"}) by (pod)

Cluster CPU:
  sum(rate(container_cpu_usage_seconds_total
    {namespace="education"}[5m]))

Cluster Memory:
  sum(container_memory_usage_bytes{namespace="education"})

📝 NOTES IMPORTANTES
═════════════════════════════════════════════════════════════════

1. Services Metrics:
   Les services education exposent automatiquement les métriques
   via cAdvisor (kubelet). Pas besoin de modifier les services!

2. Données en Temps Réel:
   Les dashboards se mettent à jour toutes les 10 secondes.
   Les données remontent 5-10 secondes après l'exécution.

3. Retention Prometheus:
   Les données sont gardées par défaut 15 jours.
   Pour production, augmenter la retention avec --storage.tsdb.retention.time

4. Persistent Storage:
   Actuellement, Prometheus et Grafana utilisent emptyDir (données perdues au redémarrage).
   Pour production, ajouter PersistentVolumes.

5. Alerts:
   Pas d'alertes configurées actuellement.
   À faire: Ajouter des alerting rules pour CPU > 80%, Memory > 90%, etc.
