🔍 ÉTAPE 5: ÉCRIRE DES REQUÊTES PROMETHEUS
═════════════════════════════════════════════════════════════════

Les requêtes PromQL permettent de récupérer les métriques.

REQUÊTES DISPONIBLES POUR ARGOCD:

1. État d'ArgoCD:
   up{job="argocd"}
   → Retourne 1 si UP, 0 si DOWN

2. Nombre de syncs totales:
   argocd_app_sync_total
   → Nombre total de synchronisations

3. Durée de réconciliation:
   argocd_app_reconcile_duration_seconds
   → Temps pris pour synchroniser

4. Info serveur ArgoCD:
   argocd_server_info
   → Informations du serveur

5. Nombre d'applications:
   count(argocd_app_info)
   → Nombre total d'apps

EXEMPLE COMPLET - Créer un graphique de syncs:

1. Ajouter un nouveau panel
2. Dans "Metrics browser", entrer:
   increase(argocd_app_sync_total[5m])
3. Cliquer "Run queries" (Ctrl+Enter)
4. Voir le graphique s'afficher
5. Changer le titre: "App Syncs (5min)"
6. Cliquer "Save" en haut à droite

🎨 ÉTAPE 6: CONFIGURER LA VISUALISATION
═════════════════════════════════════════════════════════════════

Après écrire une requête, configurer le panel:

ONGLET "VISUALIZATIONS":
   • Type: Choisir le type (Timeseries, Stat, etc.)
   • Cliquer sur un type pour preview

ONGLET "FIELD":
   • Decimals: Nombre de décimales
   • Color: Couleur du graphique
   • Min/Max: Limites de l'axe

ONGLET "PANEL":
   • Title: Titre du panel
   • Description: Description
   • Transparent: Fond transparent

ONGLET "LEGEND":
   • Display mode: Comment afficher la légende
   • Placement: Où placer la légende
   • Calcs: Afficher min/max/mean

EXEMPLE - Créer une jauge ArgoCD status:

1. Ajouter panel
2. Requête: up{job="argocd"}
3. Visualizations → "Stat"
4. Options:
   • Color mode: "Background"
   • Graph mode: "Area"
   • Text mode: "Value and name"
5. Field → Mappings:
   • Add mapping
   • Type: "Value"
   • Values: 0→"DOWN", 1→"UP"
6. Titre: "ArgoCD Status"
7. Save

🔄 ÉTAPE 10: AJOUTER DES ALERTES
═════════════════════════════════════════════════════════════════

Créer une alerte si ArgoCD down:

1. Ajouter un panel avec: up{job="argocd"}
2. Cliquer l'onglet "Alert"
3. Cliquer "Create alert from this query"
4. Configurer:
   • Condition: "Last value" "Is below" "1"
   • Duration: "For 1m"
   • Alert state: "ALERTING"
5. Cliquer "Save"

Maintenant, si ArgoCD down pendant 1 min → ALERTE!

❌ PROBLÈMES COURANTS & SOLUTIONS
═════════════════════════════════════════════════════════════════

PROBLÈME: "No data" dans le panel
SOLUTION:
  1. Vérifier la requête PromQL
  2. Cliquer "Run queries"
  3. Checker la plage horaire (top right)
  4. Essayer: increase(metric[5m]) au lieu de metric

PROBLÈME: Prometheus "DOWN" dans les targets
SOLUTION:
  C'est normal pour les services sans /metrics endpoint
  - Les services education n'exposent pas de métriques
  - Seulement ArgoCD est "UP"

PROBLÈME: Panel ne s'affiche pas
SOLUTION:
  1. Refresh la page (F5)
  2. Cliquer "Inspect" dans le panel
  3. Voir les erreurs
  4. Corriger la requête
