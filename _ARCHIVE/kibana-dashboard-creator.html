Education Platform - Event Monitoring

⏱️ Complete Setup in 5 Minutes - Follow the steps below
0 Prerequisites

✅ You already have: Event Activity Timeline visualization saved

✅ You have: filebeat-logs data with 2.6M documents

✅ Kibana is running at: http://localhost:30561

1 Visualization 1: Pie Chart - Events by Agent
  1. Go to Visualizations
  2. Click Create visualization
  3. Select Lens
  4. DRAG agent.name from left sidebar to center
  5. Wait for Pie chart to appear automatically
  6. Click Save (top right)
  7. Title: Events by Agent
  8. Click Save visualization
2 Visualization 2: Metric - Total Events
  1. Click Create visualization
  2. Select Lens
  3. DRAG @timestamp to center ONCE
  4. System automatically shows a BIG NUMBER
  5. Click Save
  6. Title: Total Events (Last 24h)
  7. Click Save visualization
3 Visualization 3: Line Chart - Activity Trend
  1. Click Create visualization
  2. Select Lens
  3. DRAG @timestamp to center
  4. Top of screen: Change chart type to Line
  5. Wait for Line chart to appear
  6. Click Save
  7. Title: Activity Trend
  8. Click Save visualization
4 Visualization 4: Horizontal Bar - Top Event Types
  1. Click Create visualization
  2. Select Lens
  3. DRAG aws.cloudtrail.event_type to center
  4. Top of screen: Change chart type to Bar (horizontal)
  5. Wait for Horizontal Bar chart to appear
  6. Click Save
  7. Title: Top Event Types
  8. Click Save visualization
5 Create Dashboard
  1. Left menu: Click Dashboards
  2. Click Create new dashboard
  3. Click Add (top)
  4. Click Add existing
  5. Search and ADD all 5 visualizations:
    • ✓ Event Activity Timeline
    • ✓ Events by Agent
    • ✓ Total Events (Last 24h)
    • ✓ Activity Trend
    • ✓ Top Event Types
  6. Click and drag visualizations to arrange them
  7. Click Save (top right)
  8. Title: Education Platform - Event Monitoring
  9. Click Save dashboard
