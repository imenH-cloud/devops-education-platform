## 🎬 COMMENT PRENDRE UN SCREENSHOT

### Sur Windows:
```
1. Appuie sur "Print Screen" (ou "PrtScn")
2. Ouvre Paint (Recherche "Paint" dans Windows)
3. Colle (Ctrl+V)
4. Sauvegarde: File → Save As
5. Nom: 01_prometheus_homepage.png
6. Type: PNG
7. Dossier: D:\project\devopsPFE\screenshots\monitoring\
```

### Alternative - Snipping Tool:
```
1. Appuie sur Win+Shift+S
2. Sélectionne la région à capturer
3. L'image se copie automatiquement
4. Colle dans Paint et sauvegarde
```

### Alternative - Chrome:
```
1. Right-click dans la page
2. Clique "Take screenshot"
3. Clique "Capture area"
4. Sélectionne la région
5. Clique "Download"
```
